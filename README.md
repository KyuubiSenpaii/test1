This game is exactly what you think. 
It's my first time building a game.
It chooses a random name out of a list of 5 letter names.
Your goal is to guess the name within 6 guesses.
The easiest way to run it is to do the fllowing steps:
  1) Click the wordleProject folder → click BiblicalWordle3.html.
  2) On that page, find the Download raw file button (top-right of the file view — it looks like a download arrow).
  3) Click it. The file saves to your Downloads folder.
  4) Go to your Downloads folder and double-click BiblicalWordle3.html. It opens in your default browser and the game runs.
